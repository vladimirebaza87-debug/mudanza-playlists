Mudanza de playlists · YouTube Music

Copia tus playlists y tu música que te gusta de una cuenta de YouTube a otra. El progreso se guarda en este navegador, así que puedes pausar y continuar otro día.

Estás abriendo la página como archivo (file://). El inicio de sesión de Google no funciona así: sírvela desde http://localhost (mira el README).

1Configuración

Pega el Client ID de OAuth de tu proyecto de Google Cloud (con la YouTube Data API v3 habilitada).

¿Cómo consigo el Client ID?
  1. Entra en console.cloud.google.com y crea un proyecto.
  2. En APIs y servicios → Biblioteca, busca YouTube Data API v3 y pulsa Habilitar.
  3. Configura la pantalla de consentimiento de OAuth como Externa y agrega como usuarios de prueba los correos de las dos cuentas (origen y destino).
  4. En Credenciales, crea un ID de cliente OAuth de tipo Aplicación web y en Orígenes de JavaScript autorizados añade:
  5. Copia el Client ID y pégalo aquí.

2Cuenta de origen: elige qué copiar

Inicia sesión con la cuenta antigua y elige las playlists. Leer cuesta muy poca cuota. Si quieres, en vez de eso puedes importar los CSV de Google Takeout.

3Plan de transferencia

Esto es lo que se va a crear en la cuenta nueva. Antes de empezar puedes cambiar los nombres o quitar listas.

4Cuenta de destino: transferir

Inicia sesión con la cuenta nueva. Esa cuenta tiene que tener un canal de YouTube creado.
